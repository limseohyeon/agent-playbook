# 작업 제목

> **한 줄 요약:** 무엇을, 왜, 어떻게 개선했는지 한 문장으로 작성  
> **핵심 결과:** 가장 중요한 성과 또는 변화

| 항목 | 내용 |
|---|---|
| 기간 | YYYY-MM-DD ~ YYYY-MM-DD |
| 프로젝트 | 프로젝트명 |
| 역할 | 담당 역할 |
| 상태 | 완료 / 진행 중 / 보류 |
| 관련 기술 | `기술` `도구` `키워드` |

---

## 1. 배경과 문제

### 기존 상황

기존에는 어떤 방식으로 작업하고 있었는가?

### 문제

- **현상:** 실제로 발생한 문제
- **영향:** 사용자·서비스·개발 과정에 미친 영향
- **원인:** 확인된 원인 또는 가설

> **핵심 문제**  
> 이번 작업에서 반드시 해결해야 했던 문제를 한 문장으로 정리한다.

---

## 2. 목표와 제약

### 목표

- [ ] 반드시 해결해야 하는 요구사항
- [ ] 만족해야 하는 완료 조건
- [ ] 확인 가능한 기대 결과

### 범위 밖

- 이번 작업에서 다루지 않는 내용
- 의도적으로 제외한 기능이나 문제

### 제약 조건

- **환경:** 운영체제, 실행 환경, 기존 시스템
- **권한:** 접근 가능한 시스템과 제한 사항
- **보안:** 민감 정보, 인증, 외부 통신 제약
- **일정·호환성:** 일정 또는 하위 호환성 요구사항
